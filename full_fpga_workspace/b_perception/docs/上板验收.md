# HDMI 与 USB TTL 上板验收

## 断电接线

- [ ] OV5640 排线方向确认并锁紧。
- [ ] FPGA 的 HDMI1 通过双头 HDMI 线连接 RK3588 的 HDMI RX。
- [ ] TFmini-S TX 连接 GPIO0_0 / A13。
- [ ] WT901 TX 连接 GPIO0_1 / A14。
- [ ] FPGA GPIO0_13 / D15 连接 CP2102 RXD。
- [ ] FPGA GND 连接 CP2102 GND。
- [ ] CP2102 的 VCC、5V、3V3 和 TXD 均不连接 FPGA。
- [ ] CP2102 USB 连接 RK3588。

## 分链路验收

1. 先不连接 CP2102，只接 HDMI。RK3588 应稳定识别 1280 x 720 progressive。
2. 再连接 CP2102。运行 `dmesg | tail -n 30` 和 `ls -l /dev/ttyUSB*`。
3. 执行：

   ```bash
   python3 sensor_link_receiver_v3.py /dev/ttyUSB0
   ```

4. 即使传感器未接好，也应每秒收到约 20 帧；此时 fresh 状态可能为 0。
5. 传感器正常时，序号连续递增，fresh 显示 1/1，距离和姿态随实物变化。
6. LED6 持续闪烁表示 FPGA 正在完成遥测帧；LED7 亮表示至少一个传感器解析器累计过错误。
7. 连续运行 30 分钟，记录 HDMI 丢锁、CRC 错误、序号跳变和传感器停更情况。

如果 HDMI 失败但串口正常，排查 HDMI1、线缆和 RK3588 HDMI RX。如果串口
失败但 HDMI 正常，排查 D15 到 CP2102 RXD、共地、设备节点和波特率。两条
链路不应互相作为成功条件。
